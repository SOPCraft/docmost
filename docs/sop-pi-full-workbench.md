# 原生Pi（智能体框架）工作台

用户要求完整接入Pi，不是一次性表单、聊天气泡模拟或关闭工具的单轮模型包装。

在现有Aside（右侧栏）增加pi-agent（智能体标签），保留历史、评论、目录的同一布局/主题/关闭机制。底部持续输入，消息/工具结果/扩展提问/真实运行状态显示在中间；收起仅隐藏，刷新从后台继续同一会话。

后台只做现有用户/空间/文档权限校验和原生协议转接，智能体执行交给独立环境中的固定Pi 1.0.2。全部官方RPC（进程通信协议）命令逐项对照类型文件，原生会话文件为聊天权威。模型、思考强度、分支/树/导出、停止/纠正/后续队列、压缩/重试、工具、技能、扩展及MCP（模型上下文协议）不能被删成一个生成接口。

资料引用是已获授权固定原稿，所有会话读取路径继承累计来源权限；不能移除引用标签后让旧聊天失去权限约束。模型对原稿的写入经现有业务接口与版本链，不能直接访问数据库。完整终端工具不能与文档后台共享凭据和文件系统。

完整范围和验收矩阵位于SOPCraft/sop（集成仓库）第12号请求的docs/implementation/PI-FULL-WORKBENCH-20261005.md。创建本文件不代表功能已经实现或部署。终端专属扩展界面、认证管理、包管理、真实模型和业务写入均继续列入完整目标，按实际证据核销。
