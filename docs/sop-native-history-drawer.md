# 原生侧栏中的历史记录

基于已合并的历史记录与版本后台能力，本次只改变界面接入，不改变保存或仓库格式。

## 交互
- 工具栏使用与评论、目录一致的时钟图标按钮，名称放入悬停提示和无障碍标签。
- 复用应用原生右侧面板、展开动画、标题和关闭控件，不创建新的全屏历史弹窗。
- 首先展示当前文档，侧栏顶部固定“当前版本”；点击该项只是退出历史预览，不恢复、不发布、不写入文档。
- 选中历史后在原正文区域显示只读内容和差异；原来的协同编辑器保持挂载但隐藏并禁止交互，不把历史正文写给协同编辑器。
- 导航、工具栏、侧栏与版本列表保持位置；已验证切换不同版本时它们的尺寸不变。
- 复用原生历史行的灰色选中样式及原有差异高亮，移除独立灰色画布、纸张阴影和大留白。
- 版本条目和悬停只展示简短变更片段；摘要仍由确定性程序提供，不使用模型。
- 日期和修改人筛选收纳在“筛选”入口，完整历史查询与真实上一版比较规则不变。
- 当前选择按文档和用户身份隔离；切换到其他侧栏或关闭后返回当前文档。

## 验证范围与阻断
开发过程中完整服务端712项、完整前端101项、类型检查和15个改动脚本文件静态检查通过。
真实登录页面已验证图标样式匹配、39条历史、原生侧栏、当前文档保持挂载、版本切换布局稳定、简短悬停、不因悬停选中、全部历史作者筛选及查看不产生新版本。
此后复核修正了移动侧栏断点和连接重试提示的等待语义；最终重跑遇到测试电脑系统盘空间耗尽，构建环境和预览服务无响应。
因此上述通过记录不能当作最终提交已完整复验；剩余侧栏联动、移动视口、深色模式与最终全量回归必须在环境恢复后完成。
保持草稿，不合并、不替换正式服务。不删除其他项目、资料或数据库来强行完成验收。
任意历史恢复和完整附件历史仍不属于本批已实现功能。
