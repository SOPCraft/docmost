# 历史操作集中到右侧

本轮执行集成仓库《历史操作全部收口到右侧》规范，沿用原生侧栏和既有版本服务。

## 界面
中间只显示历史标题、正文、表格和差异，不再包含比较工具栏、时间作者、摘要或资料范围说明，也不保留旧工具栏的占位高度。
历史标题采用原生文档标题结构、字号和内边距，历史正文容器采用同一文档宽度设置。已有工具栏只增加轻量历史预览标记，不增加高度。
版本信息、显示模式、比较基准、改动导航、摘要与资料限制全部放在右侧。比较详情默认折叠，选中信息和筛选随侧栏滚动，顶部当前版本入口固定。
原协同编辑器仍保持挂载，隐藏时禁止交互。回到当前版本仅退出历史预览，不恢复、不保存、不发布。

## 一个读取状态，两个展示位置
把原有读取状态提取为一个模型；同一只读查看器通过页面与用户绑定的显示目标，将操作控件放入侧栏。
中心正文和右侧操作共用比较请求、当前版本、模式、差异计数和导航状态，不挂载第二个读取器。
切换版本或基准时保留请求取消和身份检查；加载失败不展示前一个版本作为替代，选择变化不能被迟到请求覆盖。
显式处理跨显示位置的退出键，避免控件迁移后键盘无法关闭。保留原页面级权限检查和历史只读语义。

## 日期范围
使用原生月历组件的范围模式，输入框和月历共用同一份草稿。支持两次点击形成单日或跨月范围、悬停预览、手工输入和快捷范围。
快捷项：今天、最近7天、最近30天、本月、上个月。所有操作先改变草稿，点击应用后才查询；取消与退出键不修改已应用过滤。
清除日期并应用只移除日期条件，不移除修改人。不存在、不完整或逆序的手工日期不能应用；日历逆序点击按日期先后形成范围。
过滤边界按本机时区计算，包含结束日全天，次日零点为排他上界；不固定累加24小时处理夏令时。
月历弹出层根据实际尺寸重新计算方向及双轴位置，并限制可滚动高度，避免较小视口中超出屏幕。

## 明确边界
按住鼠标拖动选日和独立周历视图未加入本批。任意历史恢复及完整附件、批注历史不在本次完成范围。
本轮只修改客户端展示和交互，不修改后端保存、权限、数据库、仓库格式或依赖锁。
测试在3026隔离应用进行；正式3016/3017服务不替换。精确提交和实际验证范围以集成仓库对应证据文件为准。
